${context_block}아래 여러 종속항 각각에 대해 Phase 1 추가 구성 대비 분석만 작성하세요.

규칙:
- 각 종속항 보고서는 반드시 `===청구항 N===` 줄로 시작하세요. N은 입력에 주어진 청구항 번호 그대로 사용합니다.
- 입력으로 주어진 종속항을 하나도 빠짐없이 모두 작성하세요.
- 각 청구항 본문은 `### [추가 구성]` 다음 줄의 판정 형식부터 바로 시작합니다. 추가 기술 특징이 하나의 추가 구성으로만 분석되면 `(A)` 같은 임시 라벨을 붙이지 않고, 둘 이상으로 분해해야 할 때에만 `(A)`, `(B)`, `(C)` 라벨을 붙입니다. 별도 대제목이나 최종 보고서 구획은 출력하지 않습니다.

[분석 가이드라인]
1. 부모 청구항의 구성은 이미 검토되었으면 별도 분석을 생략합니다. 부모항이 입력 또는 이전 컨텍스트에 없으면 그 실체를 추정하지 말고, '에 있어서' 뒤에 직접 기재된 추가 기술 특징만 분석합니다.
2. 해당 종속항만의 추가 구성(부모항에 없는 특징)에 집중하여 담당 인용발명과 대비합니다.
3. 각 추가 구성에 대해 대응 여부와 구체적 근거를 서술합니다.
4. 대응된다고 판단하면 그 근거를, 대응되지 않는다고 판단하면 유사한 점과 불일치 이유를 명시합니다. 추가 구성이 복합 구성인 경우에는 입력, 출력, 처리 대상, 예측·생성 정보, 모델/알고리즘, 결합 관계 중 발췌로 직접 확인되는 하위 요소와 확인되지 않는 하위 요소를 구분하고, `단일 이미지 기반 처리에 대응됩니다`처럼 기술분야나 목적만 일반화한 이유는 쓰지 않습니다.
5. 부모항이 확인되는 종속항만 부모항의 인용발명 조합을 상속합니다. 부모항이 확인되지 않으면 현재 종속항의 추가 기술 특징에 대응하는 문헌만 사용합니다. 새로 결합할 수 있는 인용발명은 [인용 체인 정보]에 표시된 최대 1개뿐입니다.
6. 각 종속항에서 새로 추가된 인용발명은 해당 종속항 추가 구성에 대한 실제 거절 조합 문헌입니다. 인용발명 번호가 3 이상이어도 주지관용 입증자료나 보조자료로 축소하지 말고, 추가 구성의 직접 대응 근거와 결합 판단에 사용합니다.
7. 종속항 단계가 깊어질수록 부모항의 최종 결합 발명을 계속 상속하고, 현재 종속항에서는 [인용 체인 정보]에 표시된 새 인용발명 1개만 추가합니다.
8. 여러 발췌가 있는 경우 각 발췌의 출처와 현재 종속항의 추가 기술 특징과의 대응 관계를 구분하여 인용합니다.
9. `단일 추가 문헌 커버 상태`가 `부분 대응`이면, 새 인용발명과 부모 조합으로 대응될 수 있는 기술적 특징은 대응 가능하다고 설명하고, 남는 차이점은 별도로 명시합니다. 다만 남는 차이가 인용발명들에 이미 개시된 입력, 조건, 출력, 데이터 표현, 처리 모듈 또는 적용 대상의 통상적인 치환·확장·역할 분담으로 해소될 수 있는지 검토하고, 결합 후에도 각 인용발명의 기술적 목적과 작동 원리가 유지되는지 함께 판단합니다. 남는 차이가 이러한 통상적 구현 선택으로 설명될 수 있으면 거절 근거를 구성할 수 있는 방향으로 결론을 정리하고, 그렇지 않은 경우에만 한계와 추가 근거 필요성을 명시합니다. `대응 불충분`이면 두 번째 새 인용발명으로 보완하지 말고, 허용된 조합만으로 거절 근거를 완성하기 어렵다고 명시합니다.
10. 추가 기술 특징이 이미 인용발명들에 개시된 기능 모듈의 구체적 구현수단, 알고리즘·모델·아키텍처의 선택, 전처리·후처리 모듈, 데이터 변환·정규화·정렬·보정 수단, 샘플링·보간·업샘플링, 특징량/방향/법선/가중치 추정, 또는 공지 수치해석·최적화·재구성 알고리즘의 적용을 한정한 것인지 별도로 검토합니다. 청구항이 특별한 작용효과를 구체적으로 전제하지 않고, 치환·적용 후에도 입력, 출력, 처리 목적 및 작동 원리가 유지된다면, 공지·관용적 구현수단의 단순 치환 또는 통상적 전처리·후처리 적용으로 보아 대응 가능하다고 판단합니다.
11. 발췌는 각 종속항의 [담당 인용발명 대응 구성 데이터]의 quote와 위치를 근거로 사용합니다. 한국어 quote는 그대로 옮기고, 외국어(일본어·중국어·영어 등) quote는 인용 규칙에 따라 한국어 직역 또는 준직역 문장 다음 줄에 원문 quote와 위치를 괄호로 병기하십시오. 괄호 안 원문 quote는 문헌의 원래 언어 그대로 유지하고 영어로 바꾸지 마십시오. 요약·의역은 발췌 뒤 별도 문장으로 쓰고, 데이터에 없는 원문은 만들지 않습니다.
12. `(A)`, `(B)` 라벨을 사용한 경우에도 이 라벨은 구성대비 식별용일 뿐입니다. `차이점`과 `결론` 문장에는 `구성 (A)`, `구성 (B)`처럼 쓰지 말고 `추가 구성` 또는 해당 기술 특징 문구로 작성합니다.
